2. Seus modelos e arquivos

Preferência: GLB autocontido. GLTF pode depender de arquivos .bin e texturas externos. VRM é guardado como original, mas precisa ser convertido para GLB/FBX/OBJ para operações Meshy.

Arquivos permitidos: GLB, glTF, FBX, OBJ, STL, VRM, PNG, JPG e WebP. Limite local de 25 MB por arquivo (imagens: 20 MB). Para gerar cabelo/roupa/acessório por imagem, prefira uma foto recortada que mostre somente a peça desejada.

3. Conectar IA (Meshy)

A chave é enviada somente ao servidor local e mantida na memória enquanto o Studio estiver aberto. Não é salva no preset, navegador ou ZIP. Quando você iniciar uma tarefa, os arquivos escolhidos e a descrição serão enviados à API Meshy.

Verificando conexão…

A criação de tarefas pode consumir créditos pagos da sua conta Meshy. O Studio só envia uma tarefa quando você clica em um botão e confirma. Envie apenas arquivos que você tem direito de compartilhar com o provedor.

4. O que deseja criar ou alterar?

Processar uma cópia do modelo selecionado: escolha a base ou um acessório acima. No modo Preservar, somente arquivos classificados como acessório podem ser processados; a base fica bloqueada. Retexturizar altera materiais/texturas; remalhar altera topologia/contagem de faces, não remodela por si só rosto ou corpo.

Os GLBs gerados são arquivos separados. O encaixe automático de roupas/cabelos, transferência de pesos e integração ao esqueleto ainda precisam ser feitos no Blender/Unity.

Do programa ao VRChat

  1. Monte o avatar aqui (aparência + acessórios) e clique em Exportar pacote.
  2. Abra seu projeto Unity com o VRChat SDK (Avatars 3.x) e copie a pasta Unity/Assets/VRChatAvatarStudio para dentro de Assets.
  3. No menu do Unity: VRChat Avatar Studio ▸ Importar e configurar tudo e escolha o arquivo .vrcavatar.json.
  4. Abra VRChat SDK ▸ Show Control Panel, faça login, e use Build & Publish.

Acessórios

  • Peças do mesmo grupo viram uma só malha: um objeto que liga/desliga no menu do VRChat.
  • Espelhar cria a cópia do outro lado (ex.: chifres, pulseiras).
  • Balançar dá um PhysBone à peça (sininho, capa, antena).
  • Cada grupo extra conta como uma malha a mais no ranking de desempenho — junte peças em poucos grupos.

Quero um avatar com acabamento de VRChat

O gerador procedural deste Studio cria uma base estilizada editável. Ele ainda não substitui uma personagem artística com malha esculpida, cabelo modelado e texturas pintadas. Para esse nível de acabamento, use uma base 3D própria e depois prepare o upload no fluxo compatível com VRChat.

  1. Crie o personagem no VRoid Studio, que oferece muitos controles de aparência e pintura manual.
  2. Para o fluxo VRChat do VRoid, exporte como XAvatar e importe no Unity com o XWear Packager, seguindo o guia oficial.
  3. Use o VRChat SDK para validar o avatar e fazer o Build & Publish.

Guia oficial VRoid → VRChat · Guia oficial do VRChat

Atenção: confira a licença de cada modelo, roupa e acessório. Os modelos de exemplo do VRoid não são automaticamente CC0, e nem todo asset permite redistribuição.
